# dev-notes

작업하면서 언제든 열어서 참고하는 개인 문법 노트.
특정 프로젝트에 묶이지 않게, **어디서든 다시 쓸 수 있는 형태**로 정리한다.

## 문서

| 문서 | 내용 | 추가 방식 |
| --- | --- | --- |
| [javascript.md](javascript.md) | 바닐라 JavaScript ↔ jQuery 대응 | 질문·체크·해석한 것 계속 추가 |

## scss.md / css.md 나누는 기준

```text
브라우저가 그대로 이해한다       → css.md
컴파일(SCSS → CSS)해야만 동작한다 → scss.md
```

| css.md | scss.md |
| --- | --- |
| `var(--color)` CSS 변수 | `$color` SCSS 변수 |
| `calc()`, `clamp()`, `:is()`, `:has()` | `@mixin` / `@include` |
| CSS 기본 중첩(`&`) — SCSS 중첩과 비교 메모 | `%placeholder` / `@extend` |
| 속성 · 값 · 선택자 · 미디어쿼리 | `@use` / `@forward`, `@each` / `@if`, 함수 |

SCSS는 CSS 문법을 전부 그대로 쓸 수 있으므로, css.md 내용은 SCSS 파일에서도 그대로 사용한다.

## 항목 형식

| 문서 | 형식 |
| --- | --- |
| javascript | 설명 → JavaScript → jQuery → 실무 예 → 한 줄 요약 |
| html | 설명 → 사용법 → 예 → 주의(접근성 등) → 한 줄 요약 |
| scss | 설명 → SCSS → **컴파일된 CSS 결과** → 주의 → 한 줄 요약 |
| css | 설명 → 문법 · 값 → 예 → 주의(브라우저 지원 등) → 한 줄 요약 |

- 제목 단계: `#` 문서 제목 / `##` 분류 / `###` 항목 / `####` 항목 안 소제목
- 번호: `분류-항목` (예: `3-4`). 새 항목은 맞는 분류 끝에 붙이고 목차도 같이 갱신한다.
- 실무 예시에 회사 코드를 넣을 때는 레포 공개 여부를 확인하고, 필요하면 ID · 클래스명을 일반적인 이름으로 바꾼다.

## 업데이트 규칙

| 요청 | 반영 위치 |
| --- | --- |
| 새 문법 질문 | 맞는 분류에 새 항목 추가 + 목차 · 빠른 비교 갱신 |
| 코드 해석 요청 | 관련 항목의 "실무 예"에 추가. 여러 문법이 섞인 코드면 "코드 읽기" 분류에 추가 |
| 코드 체크 요청 | 발견된 실수 · 헷갈린 점을 해당 항목의 "주의"에 추가 |
